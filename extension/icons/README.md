# Edge 扩展提交资源

本目录包含 Edge 扩展商店提交所需的图标和说明。

## 徽标尺寸要求

| 尺寸 | 用途 |
|------|------|
| 128x128 | Edge 商店展示主图（必需） |
| 48x48 | 扩展管理页面 |
| 32x32 | 工具栏 |
| 16x16 | 小图标 |

## 图标文件

- `icon-128.png` - 128x128 主图标
- `icon-48.png` - 48x48
- `icon-32.png` - 32x32
- `icon-16.png` - 16x16
- `logo-512.png` - 512x512 原始设计图（用于生成各尺寸）

## 生成步骤

1. 将 AI 生成的原始图标另存为 `logo-512.png`
2. 运行 `resize-icons.ps1` 自动生成各尺寸：

```powershell
.\resize-icons.ps1
```

## 注意事项

- 所有图标必须为 PNG 格式
- 背景透明（PNG 支持 alpha 通道）
- 不要拉伸或变形图像
- 确保 16x16 版本在小尺寸下仍然清晰可辨
